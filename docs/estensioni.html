Estensioni.

Non tutte le posizioni meritano la stessa profondità di ricerca. Le estensioni riconoscono i momenti critici — uno scacco, un'unica risposta possibile, un pedone a un passo dalla promozione — e approfondiscono la ricerca esattamente dove serve.

Check Extension One-Reply Extension Passed Pawn Extension Singular Extension
concetto base

Perché estendere la ricerca?

La ricerca a profondità fissa può "mancare" sequenze tattiche che iniziano esattamente al limite della profondità. Le estensioni aggiungono +1 ply (o frazioni) in posizioni dove la ricerca superficiale sarebbe insufficiente — senza aumentare la profondità globale in modo indiscriminato.

In GMVT le estensioni vengono accumulate in una variabile ext e applicate come prof - 1 + ext nella chiamata ricorsiva.

⚖️
Limite di estensione — evitare l'esplosione
Le estensioni non sono illimitate: GMVT applica un cap (ext ≤ 2) per evitare che sequenze di scacchi artificiali portino a profondità infinite. L'estensione totale non può superare la profondità iniziale.
estensione 01

Check Extension

Quando una mossa mette il re avversario in scacco, la posizione risultante è di per sé critica: il giocatore in scacco ha opzioni limitate e spesso obbligate. Tagliare la ricerca in questo momento significherebbe perdere sequenze tattiche fondamentali.

GMVT estende di +1 ply ogni volta che la mossa analizzata causa uno scacco. Questo è uno dei contributi più importanti alla forza tattica del motore.
Estensione
+1 ply
Condizione
in_scacco()
Cap globale
+2 ply
check_extension.cpp C++ 
int ext = 0;

// Check Extension: mossa corrente mette in scacco?
esegui_mossa(s, mossa);
if (in_scacco(s))
{
    ext = 1;   // +1 ply: la posizione di scacco richiede analisi più profonda
}

// Applica l'estensione nella chiamata ricorsiva
int val = -minimax(s,
    min(prof-1+ext, MAX_PLY),  // non superare la profondità massima
    -beta, -alfa);
estensione 02

One-Reply Extension

Se il giocatore in scacco ha una sola risposta legale, la posizione è di fatto "forzata": qualunque analisi parziale sarebbe fuorviante. L'estensione One-Reply aggiunge +1 ply quando il generatore di mosse produce un singolo candidato legale.

Questo è particolarmente utile nei matti a lungo termine dove una serie di scacchi con risposta unica porta inevitabilmente alla conclusione.
Condizione
1 mossa legale
Estensione
+1 ply
Combinabile
Con Check Ext.
one_reply.cpp C++ 
auto mosse = genera_mosse_legali(s);

// One-Reply Extension: se c'è una sola risposta legale
if (mosse.size() == 1)
{
    ext = min(ext + 1, 2);  // +1 ply, con cap globale a 2
}

int val = -minimax(s, prof-1+ext, -beta, -alfa);
// One-Reply Extension: la mossa forzata merita più analisi di una posizione con molte alternative
estensione 03

Passed Pawn Extension

Un pedone passato — non bloccato da pedoni avversari sulla sua colonna né sulle colonne adiacenti — è una minaccia crescente nei finali: se raggiunge la traversa finale diventa una regina. GMVT estende la ricerca quando un pedone passato avanza nelle ultime due traverse (6ª o 7ª fila per il bianco).

Questa estensione è fondamentale per valutare correttamente le corse al pedone passato nei finali, dove ogni mossa conta.
Condizione
Fila 6 o 7
Estensione
+1 ply

passed_pawn.cpp C++ 
// Passed Pawn Extension: pedone passato nelle ultime traverse
bool e_pedone = (pezzo_mosso == PEDONE);
int  fila_dest = fila_di(mossa.dest);
bool avanzato  = (colore == BIANCO) ? (fila_dest >= 6) 
                                          : (fila_dest <= 3);

if (e_pedone && avanzato && e_passato(s, mossa.dest))
{
    ext = min(ext + 1, 2);  // pedone passato avanzato → analisi più profonda
}
estensione 04

Singular Extension (SE)

La Singular Extension è la più sofisticata tra le estensioni: si applica quando una mossa è singolarmente migliore di tutte le alternative. GMVT verifica questo cercando con una finestra ridotta (singolar probe) escludendo la mossa candidata: se nessuna altra mossa supera alpha - margine, la mossa è davvero speciale e merita +1 ply extra.
Margine probe
50 cp
Depth probe
(d-1)/2
Estensione
+1 ply
Richiede
TT hit
singular_ext.cpp C++ 
// Singular Extension: la mossa TT è davvero la migliore?
if (tt_mossa == mossa_corrente
    && tt_depth >= prof - 3
    && prof >= 8)
{
    // Cerca senza la mossa TT con finestra ridotta e profondità dimezzata
    int margine   = tt_val - 50;
    int probe_val = minimax_escludi(s, (prof-1)/2,
                        margine-1, margine, mossa_corrente);

    if (probe_val < margine)   // nessuna altra mossa è competitiva
        ext = 1;              // questa mossa è singolare → +1 ply
}
🔬
Come funziona il "singular probe"
GMVT esegue una ricerca escludendo la mossa migliore dalla TT (tabella trasposizioni). Se anche senza quella mossa il valore scende sotto tt_val - 50, significa che la mossa TT è davvero l'unica buona — e merita un'analisi più profonda.
