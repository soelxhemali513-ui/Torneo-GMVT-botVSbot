Valutazione.

Quando la ricerca raggiunge la profondità massima, deve dare un numero alla posizione. Questo numero — la valutazione statica — combina materiale, posizione dei pezzi, struttura pedonale, sicurezza del re e molto altro in un singolo centipedone.

componente 01

Piece-Square Tables (PST)

Le Piece-Square Tables assegnano un bonus (o malus) a ogni pezzo in base alla casella che occupa. Un cavallo in d5 (centro) vale molto di più di un cavallo in a1 (angolo). GMVT utilizza PST separate per il middlegame e l'endgame, interpolate dalla valutazione tapered.

I valori sono codificati come array 64 interi in centipedoni, dalla prospettiva del bianco (per il nero vengono ribaltati).

int valuta_pezzo(Pezzo p, int casella, float fase)
{
    int mg = PST_MG[p.tipo][casella];
    int eg = PST_EG[p.tipo][casella];
    return taper(mg, eg, fase);  // interpolazione lineare
}
componente 02

Tapered Evaluation

Gli scacchi hanno tre fasi: apertura, mediogioco e finale. Le strategie cambiano radicalmente: nel mediogioco il re deve stare al sicuro; nel finale deve attivizzarsi e avanzare. La Tapered Evaluation interpola continuamente tra i valori middlegame (MG) ed endgame (EG) in base al materiale rimasto sulla scacchiera.

La fase è calcolata sommando il materiale non-pedone: da un massimo di 24 (posizione iniziale) a 0 (solo re).

Middlegame puro (fase=24) Fase: 14/24 — 58% MG + 42% EG Endgame puro (fase=0)
tapered_eval.cpp C++ 
// Valori di fase per ogni tipo di pezzo (non-pedone)
const int FASE_PEZZO[] = { 0, 1, 1, 2, 4, 0 }; // P,N,B,R,Q,K
const int FASE_MAX = 24;

int calcola_fase(Scacchiera& s) {
    int fase = 0;
    for (auto& p : s.pezzi)
        fase += FASE_PEZZO[p.tipo];
    return min(fase, FASE_MAX);
}

// Interpolazione tapered tra MG ed EG
int taper(int mg, int eg, int fase) {
    return (mg * fase + eg * (FASE_MAX - fase)) / FASE_MAX;
    // fase=24 → puro MG; fase=0 → puro EG
}
📊
Esempio: il re nel tapered eval
Nel middlegame il re in d1 (arrocco mancato) ha un malus di -30 cp. Nello stesso endgame, lo stesso re in d4 (centro) ha un bonus di +25 cp. Il tapered eval garantisce questa transizione continua senza salti bruschi.
componenti 03–04

Struttura Pedonale & Sicurezza del Re

03
Struttura Pedonale
Pedoni isolati, doppiati e passati
GMVT valuta la struttura pedonale cercando:

Pedone isolato (malus −20 cp): non ha pedoni amici nelle colonne adiacenti — vulnerabile e difficile da difendere.

Pedone doppiato (malus −15 cp): due pedoni dello stesso colore sulla stessa colonna — il retrostante è bloccato.

Pedone passato (bonus +20–50 cp): nessun pedone avversario può fermarlo — potenziale futura regina.
04
Sicurezza del Re
Scudo pedonale e attacchi al re
La sicurezza del re è uno dei fattori più importanti nel mediogioco:

Scudo pedonale: GMVT premia i pedoni nelle tre caselle davanti al re dopo l'arrocco (f2, g2, h2 per arrocco corto).

Colonne aperte verso il re: malus se una colonna davanti al re non ha pedoni — le torri avversarie possono penetrare facilmente.

Attaccanti vicini: somma pesata dei pezzi avversari che attaccano la zona del re.
pawn_structure.cpp C++ 
int valuta_pedoni(Scacchiera& s)
{
    int score = 0;

    for (int col = 0; col < 8; col++)
    {
        int n_bianchi = pedoni_colonna(s, BIANCO, col);
        int n_neri    = pedoni_colonna(s, NERO,   col);

        if (n_bianchi > 1) score -= 15 * (n_bianchi - 1); // doppiati
        if (n_neri    > 1) score += 15 * (n_neri - 1);

        // Pedone isolato: nessun amico nelle colonne adiacenti
        bool iso_b = !pedoni_adiacenti(s, BIANCO, col);
        if (n_bianchi > 0 && iso_b) score -= 20;  // malus isolato
    }

    // Bonus pedoni passati
    for (auto& p : pedoni_passati(s, BIANCO))
        score += 20 + fila_di(p) * 5;  // più avanzato = più bonus

    return score;
}
componenti 05–06

Mobilità & Bonus Speciali

Oltre a materiale e posizione, GMVT valuta la libertà di movimento dei pezzi e alcune strutture speciali che gli scacchisti sanno essere vantaggiose.
05
Mobilità
Numero di mosse legali disponibili
Un pezzo con più caselle raggiungibili è più attivo e utile. GMVT assegna un bonus per ogni mossa legale disponibile — con pesi diversi per ogni tipo di pezzo. Un cavallo con 8 mosse vale ~16 cp in più di uno con 2 mosse.

Pesi mobilità: Cavallo: +2/mossa, Alfiere: +3/mossa, Torre: +2/mossa, Donna: +1/mossa.
06
Coppia Alfieri
Bonus per possedere entrambi gli alfieri
Avere entrambi gli alfieri (campi chiari + scuri) è un vantaggio strutturale riconosciuto: controllano caselle complementari e sono potentissimi in posizioni aperte. GMVT assegna un bonus di +30 cp se il giocatore possiede entrambi gli alfieri.

Bonus aggiuntivo: Torri su colonne aperte (+15 cp/torre) e Torri su colonne semiaperte (+8 cp/torre).
mobility_bonus.cpp C++ 
int valuta_mobilita_e_bonus(Scacchiera& s)
{
    int score = 0;

    // Mobilità pezzi (mosse disponibili × peso)
    const int W_MOB[] = { 0, 2, 3, 2, 1, 0 };  // P,N,B,R,Q,K
    for (auto& p : s.pezzi_bianchi)
        score += W_MOB[p.tipo] * mobilita(s, p);

    // Coppia alfieri
    if (conta_alfieri(s, BIANCO) == 2)
        score += 30;  // bonus coppia alfieri

    // Torri su colonne aperte/semiaperte
    for (auto& t : torri(s, BIANCO)) {
        if (colonna_aperta(s, col_di(t)))     score += 15;
        else if (colonna_semiaperta(s, col_di(t))) score += 8;
    }

    return score;
}
