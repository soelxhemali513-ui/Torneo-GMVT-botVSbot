Architettura del motore

GMVT combina ricerca ad albero, potatura aggressiva e valutazione posizionale dettagliata per giocare in modo efficiente e competitivo.

🔍
Ricerca
Esplorazione dell'albero di gioco con profondità incrementale e finestre di aspirazione.
  • Iterative Deepening (prof. 1→16)
  • PVS — Principal Variation Search
  • Quiescence Search (solo catture)
  • Aspiration Windows
Approfondisci la ricerca
✂️
Potatura (Pruning)
Eliminazione dei rami non promettenti per ridurre il fattore di ramificazione.
  • Alfa-Beta Pruning
  • Null Move Pruning (NMP)
  • Reverse Futility Pruning (RFP)
  • Late Move Reduction (LMR)
  • ProbCut
  • Mate Distance Pruning
Approfondisci la potatura →
📡
Estensioni
Approfondimento selettivo della ricerca nelle posizioni tatticamente critiche.
  • Check Extension — scacco
  • One-reply Extension — unica risposta
  • Passed Pawn Extension — pedone passato
  • Singular Extension (SE)
Approfondisci le estensioni →
⚖️
Valutazione Statica
Stima del valore di una posizione considerando fase di gioco, struttura e attività dei pezzi.
  • Piece-Square Tables (middlegame + endgame)
  • Tapered eval — interpolazione per fase di gioco
  • Struttura pedonale
  • Sicurezza del re
  • Mobilità dei pezzi
  • Coppia alfieri / torri su colonne aperte
Approfondisci la valutazione →
🏗️
Infrastruttura
Componenti di basso livello che accelerano la ricerca e gestiscono casi speciali.
  • Hash Zobrist — identificazione univoca posizioni
  • Tabella Trasposizioni (TT) — cache nodi analizzati
  • IID — Internal Iterative Deepening
  • Regola 50 mosse / rilevamento ripetizioni
  • Contromossa (countermove heuristic)
  • Opening Book — ~60 linee di apertura
